## Novidades do Vapt 1.2.2

### Cache da memória (Otimizações)
Para **PC com pouca RAM que dá travadinhas em jogo**: limpa a lista *standby*, o cache de arquivos que o Windows guarda na memória que sobra. É o mesmo que o "Empty Standby List" do RAMMap, da Microsoft.

- Mostra quanta memória está livre de verdade e quanto é cache, e **diz se vale a pena limpar** (só quando a memória livre acabou).
- O **Turbo para jogar** também limpa o cache sozinho, mas só se a memória livre estiver no limite.
- Não mexe na memória dos programas abertos, que é o que os "limpadores de RAM" fazem e deixa tudo mais lento.
- Precisa do Vapt como administrador.

> Com RAM sobrando, limpar não deixa nada mais rápido: o Windows usa esse cache para abrir os programas mais rápido e o libera sozinho quando precisa.
