## Novidades do Vapt 1.2.1

- **Sensores do processador sem clicar em nada**: o driver PawnIO agora vem junto com o Vapt e se instala sozinho na primeira vez que ele abre (o Windows pede permissão uma vez). Com ele aparecem a temperatura e o consumo da CPU.
- **Sensores**: os filtros (Temperatura, Clock, Uso, Consumo…) rolam para o lado quando a janela é estreita, inclusive com a roda do mouse.
- Publicação no GitHub Actions atualizada para o Node 24.

## Baixar
**[Vapt.App-win-Setup.exe](https://github.com/blat0r/Vapt/releases/download/v1.2.1/Vapt.App-win-Setup.exe)** para a maioria. Também há `.msi` (todos os usuários) e `Portable.zip` (sem instalar). Quem já tem a 1.1.0 ou mais nova recebe esta sozinho.

> Ainda não assinado digitalmente: se aparecer "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
